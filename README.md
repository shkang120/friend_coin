🪙 친구 코인 (Friend Coin) 프로젝트 명세서
친구들의 사회적 신용과 행동을 기반으로 주가가 실시간으로 변동하는 프라이빗 투자 클럽 및 마피아 게임 형식의 풀스택 웹 애플리케이션입니다.

🛠️ 기술 스택 (Tech Stack)
Frontend
Language: JavaScript (ES6+), HTML5, CSS3

Library & UI:

Chart.js (실시간 주가 흐름 시각화 및 애니메이션 엔진)

Toss 스타일의 모던하고 깔끔한 컴포넌트 중심 디자인 적용

하단 고정 네비게이션 바 레이아웃 및 모바일 뷰 최적화 padding 패치

Hosting: Vercel (https://friend-coin.vercel.app)

Backend
Framework: Python FastAPI

Server: Uvicorn, Render Web Service (https://friend-coin-backend.onrender.com)

Libraries: pydantic, httpx, python-dotenv, python-multipart

Database
NoSQL: MongoDB Atlas (Cloud)

Driver: PyMongo Collection Control (friend_coin_db)

🚀 핵심 기능 총정리 (Core Features)
1. 회원가입 및 구글 OAuth 2.0 보안 인증
구글 GIS(Google Identity Services) 연동: 가짜 이메일 도용을 전면 차단하기 위해 로그인 시 구글이 발급한 위조 불가능한 정식 ID 토큰(JWT)을 활용합니다.

초기 닉네임 설정: 신규 가입 유저 판별 기능(isNewUser)을 갖추고 있으며, 정규식을 통해 특수문자를 차단하고 DB 내 중복 닉네임을 실시간 검증합니다.

플랫폼 호환성: 모바일과 구형 PC(윈도우 10 등) 환경 모두에서 이모지가 깨지지 않도록 전용 웹 폰트 폴백 스택과 클래식 이모지 최적화를 반영했습니다.

2. 프라이빗 투자 클럽 및 실시간 라운지
방 개설 및 입장: 유저가 방을 개설하면 6자리의 고유 알핀넘버 코드(UUID 기반 랜덤 코드)가 생성되며, 친구들은 이 코드를 입력해 클럽에 참여합니다.

라운지 채팅방: 클럽 내부 유저들 간의 소통을 위한 독립 공간으로, 내가 보낸 메시지(우측 파란색)와 타인이 보낸 메시지(좌측 회색 및 이름 표기)를 시각적으로 분리하고, 채팅 전송 시 스크롤이 자동으로 최하단에 포커싱되도록 제어합니다.

실시간 글로벌 시황 전광판: 전국 통합 1위 유저의 정보와 최신 공지사항이 흐르는 전광판(Ticker) UI가 상단에 실시간으로 구동됩니다.

3. 유저 코인 평가 시스템 (👍호평 / 👎악평)
평가 티켓 제한: 모든 유저는 매주 월요일 오전 8시(KST)에 호평권 2장, 악평권 2장을 자동으로 리필 받습니다.

주가 변동 가중치: 주가의 변동폭은 타겟 유저의 '기준 주가(basePrice)'를 기준으로 비율 계산(+1%, +2%, +3% 또는 -1%, -2%, -3%)되어 공정하게 증감합니다.

평가 사유 작성 필수화: 악성 무차별 난타를 막기 위해 서술형 사유 작성을 필수로 제한하며, 미입력 시 전송이 차단됩니다.

타겟 알림(Notification) 연동: 평가가 완료되면 피평가 유저의 알림 탭에 [👍호평] 수환님의 평가: 어제 롤 트롤함과 같은 상세 로그가 실시간으로 쌓입니다. (데이터 낭비 방지를 위해 최근 30개 제한 보관)

4. Chart.js 기반 실시간 주가 흐름 차트
내 정보 & 친구 정보 독립 차트: 프로필 모달 및 상세 보기 클릭 시 실시간 주가 변동 이력을 선형 그래프로 렌더링합니다.

다이내믹 컬러링 및 애니메이션: 첫 시작가 대비 현재 주가가 높으면 Red(우상향/호재), 낮으면 Blue(우하향/악재) 테마 채우기가 자동으로 적용되며, 1.2초간 부드럽게 꿀렁이는 easeOutQuart 애니메이션이 실행됩니다.

X축 날짜 가독성 패치: 주가 변동 시점의 한국 표준시(KST) 데이터를 백엔드가 계산하여 기록하며, 바닥 X축에는 글씨 짤림과 겹침이 없도록 날짜(MM.DD)만 쾌적하게 정렬하고 점 위에 마우스를 올렸을 때만 시/분까지 툴팁으로 디테일하게 표기됩니다.

5. 주주총회 법정 및 재판 시스템
기소장 상정 기능: 특정 유저를 타겟으로 안건(🚨 상장폐지 심사 건 / 🌱 코인 회생 재상장 건)과 구체적인 탄핵/구제 사유를 명시해 재판을 발의할 수 있습니다.

과반수 정족수 투표제: 클럽 참여자 전체 인원의 과반수(50% + 1명)가 찬성 혹은 반대 표결을 달성하면 즉시 실시간 최종 판결이 내려집니다.

판결 처리:

상장폐지 패스: 유저 상태가 delisted로 변경되며 주가가 0p로 고정되고 모든 보상/출석체크 버튼이 잠깁니다.

코인 회생 패스: 지옥에서 부활하여 상태가 active로 재전환되며 주가가 10,000p로 재상장됩니다.

6. 일일 출석체크 및 보상 시스템
매일 출석체크: 하루에 한 번 버튼을 클릭하여 안전하게 주가를 +50p 올릴 수 있습니다.

광고 시청 보상 보너스: 3초간의 고정 락(Lock) 타이머 광고 시청 완료 시 보상이 주어집니다.

출석 보상 2배: 하루 한 번 출석 보상에 +50p를 추가 획득합니다.

티켓 추가 충전: 하루 한 번 광고 시청을 통해 호평권/악평권을 각각 1장씩 보너스로 즉시 충전합니다.

주간 보너스: 매주 1회 평가권을 추가로 수급할 수 있는 보너스 밸런스 장치가 구현되어 있습니다.

7. VIP 멤버십 및 커스터마이징
프리패스 시스템: VIP 계정은 귀찮은 3초 광고 타이머를 대기 시간 없이 즉시 통과하여 보상을 획득합니다.

커스텀 네임 컬러 픽커: VIP 룸 관리 섹션에서 자신이 원하는 Hex 컬러코드를 선택하면, 글로벌 랭킹, 참여자 목록, 채팅방 등 앱 전체에서 내 이름에 해당 색상 스타일이 실시간 동적 반영됩니다.

프로필 아바타 믹스: 10종의 Dicebear 고품질 아바타 풀을 기본 제공하며, 기기 내 사진을 업로드하면 백엔드에서 Base64로 안전하게 압축 컨버팅되어 전용 CDN(ImgBB API) 링크로 프로필 사진이 영구 저장됩니다.

8. 동적 칭호 및 업적 시스템
스탯 기반 업적: 누적 호평 2회 이상 시 👼천사, 누적 악평 2회 이상 시 😈악마, 기소 및 재판 참여 2회 이상 시 ⚖️법정단골 등 데이터 조건 만족 시 실시간 토스트 알림과 함께 영구 칭호 뱃지가 부여됩니다.

랭킹 기반 동적 칭호: 실시간 글로벌 통합 스코어 계산을 통해 👑1위, 🚀떡상왕, 👑VIP 등의 명예 뱃지가 유저 프로필 아래에 실시간으로 인카운터됩니다.

🛡️ 엔지니어링 및 보안 고도화 (Security Patches)
현재 웹 서비스의 취약점을 보완하기 위해 설계된 핵심 데이터 보안 아키텍처입니다.

클라이언트 조작 방지 (Anti-F12 Console Tampering)

초기 버전의 프론트엔드 연산 방식을 탈피하고, 출석체크 및 광고 보상 연산 로직을 백엔드 파이썬 서버 내부로 100% 이전시켰습니다.

브라우저 개발자 도구 콘솔창에서 임의로 myProfile.price = 99999999를 입력한 뒤 서버 저장을 시도하더라도, 백엔드 저장 엔드포인트(/api/save)에서 데이터 위변조 필터를 가동하여 돈, 티켓, 히스토리 등의 금융 핵심 배열 데이터를 철저히 무시하고 튕겨내도록 보안 차단막을 형성했습니다.

구글 ID 토큰 실시간 지문 판독 (Identity Token Spoofing Protection)

이메일 텍스트 문자열만 가짜로 적어 남의 계정을 도용 및 파괴하던 API 취약점을 전면 수정했습니다.

프론트엔드의 모든 중요 액션 데이터 요청 시 HTTP 헤더에 구글의 암호화된 Authorization: Bearer ID_TOKEN을 강제 동봉하도록 규정했습니다.

백엔드는 요청을 수신하면 구글 오센티케이션 API 서버와 실시간 백채널 통신을 수행하여 해당 신분증의 위조 여부 및 토큰 내 실제 소유주 이메일을 직접 추출·대조하는 '양방향 서명 검증 파이프라인'을 가동합니다. 명의가 불일치할 경우 무조건 입구에서 차단됩니다.

셀프 평가(거울 보고 칭찬하기) 차단 정책

유저가 화면 우회 API 조작 도구를 이용해 평가자 이메일과 피평가자 이메일을 동일하게 매칭하여 전송할 경우, 백엔드 로직 단계에서 evaluator_email == target_email 유효성 검사를 통해 자신을 평가할 수 없도록 강제 에러 예외 처리를 설계하여 게임 내 인플레이션 버그를 원천 봉쇄했습니다.
