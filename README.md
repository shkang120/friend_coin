# 📝 [개발 일지] 친구들의 평판을 주식으로? '친구 코인' 프로토타입 개발기

## 1. 프로젝트 시작 배경
우리가 일상에서 흔히 겪는 "친구와의 약속 지각", "밥 사주기" 같은 정성적인 경험들을 수치화해서 보여주면 어떨까? 최근 숏폼 유행이나 밈(Meme)에서 착안하여, 친구들의 평판을 '코인(주식)' 차트로 시각화하는 가벼운 SNS 웹 앱 프로토타입을 기획했다. 

단순히 점수를 올리고 내리는 것을 넘어, 실제 주식 앱(토스 증권 등)의 UI/UX를 벤치마킹하여 사용자에게 '진짜 거래하는 듯한 타격감'을 주는 것을 목표로 삼았다.

## 2. 핵심 기획 및 차별점
앱이 감정싸움으로 번지거나 흥미를 잃지 않도록, 룰(Rule) 설계에 가장 많은 공을 들였다.

### ⏰ 현실 시간을 반영한 장 시간 도입 (Killer Feature)
* 매일 `08:00 ~ 24:00`을 '장 중'으로 설정.
* 장외 시간(새벽)에 발생한 평가는 즉시 반영되지 않고 `Queue(대기열)`에 쌓인다.
* 아침 8시 장이 시작되는 순간, 밤새 쌓인 평가가 한 번에 정산되며 차트가 폭등/폭락하게 만들어 아침마다 앱을 켜게 만드는 강력한 리텐션 요소를 부여했다.

### 📉 하이브리드 변동 계산 로직
* 평가는 `-1% ~ -5%`의 '비율'로 깎이도록 설계하여 주가가 높을수록 타격이 크도록 했다.
* 단, 주가가 너무 낮을 때 깎이는 포인트가 무의미해지는 맹점을 막기 위해 자바스크립트의 `Math.max()`를 활용해 **'최소 하락액(예: 100p)'**을 보장하는 방어 로직을 추가했다.

### 🤝 상호 수락 시스템과 주주총회
* '호평'은 즉시 반영되지만, '악평'은 상대방의 수락이 필요하다. 
* 억울할 경우 거절 버튼을 눌러 그룹 내 친구들이 참여하는 **'주주총회(투표)'** 안건으로 회부할 수 있는 소셜 기능을 기획했다.

## 3. 기술 스택 및 프론트엔드 구현
* **Tech:** HTML, CSS, Vanilla JavaScript
* **Library:** `Chart.js` (실시간 변동 차트 렌더링)
* **Storage:** `LocalStorage` (서버 연동 전 클라이언트 데이터 임시 저장)
* **Architecture:** * 별도의 프레임워크(React 등) 없이 SPA(Single Page Application) 느낌을 내기 위해 CSS `transform: translateX()`를 활용해 뷰(View) 간의 부드러운 스와이프 애니메이션을 구현했다.
  * 데이터와 UI를 완벽히 분리하여, 주가가 변동될 때마다 `history` 배열에 날짜와 가격이 `Push` 되고 차트가 즉시 다시 그려지도록 상태 관리를 세팅했다.
  * 차트 렌더링 시 Y축 여백(Buffer)을 동적으로 계산하여 실제 주식 차트와 같은 묵직한 타격감을 구현했다.
